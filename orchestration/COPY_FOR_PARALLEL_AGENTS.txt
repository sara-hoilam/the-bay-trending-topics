REQUIRED STEPS (in order):

1. Open and capture each of these live boards RIGHT NOW (not from training data):
   - Google Trends Trending Now for HK, US, GB, MO, JP, SG, IN
     URL pattern: https://trends.google.com/trending?geo=HK&sort=search-volume&hours=48

     ⚠ Read volumes from the ON-SITE TABLE (e.g. "20K+ searches") — NOT from RSS feeds.

   - TikTok Creative Center hashtags: https://ads.tiktok.com/business/creativecenter/inspiration/popular/hashtag/pc/en

3. Using prompts/gba-pulse-trend-scoring.md, build topicCandidates[]:
   - Normalize all rows from all boards into unique real-world stories
   - Score each: volume (35%) + velocity (35%) + cross-platform (30%) = compositeScore
   - Sort descending by compositeScore
   - Include at least 15 candidates

4. Set windowHours: 48, refreshedAt to current ISO timestamp (HKT).

5. Keep disclaimer: "" (empty string — do not paste methodology notes into the banner).

6. Do NOT add the standalone preview ribbon.

7. Save to orchestration/fragments/trendwatch.html — keep the model-tag line, <svg> sprite
   (tw-icon-* symbols), and <div id="trend-watch-root"></div> unchanged.

8. Run: node scripts/merge-briefing-panels.mjs
