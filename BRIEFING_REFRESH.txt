GBA Pulse — manual refresh in Cursor (Composer 2 · Claude Sonnet 4.6)
================================================================================

Goal
----
Fill `index.html` in this repo: Trending News tab = merged overall; optional Claude/Composer panels (hidden in UI). No database — you overwrite fragments, merge, then git push to your live host (GitHub Pages, Netlify, Vercel, S3, etc.).

GPT-5.5 is **not** used in the Trending News workflow.

What to attach each run
-------------------------
In every Cursor chat, @-mention (or attach) at least:

  - prompts/gba-pulse-curator-prompt.md
  - references/source-links.md
  - templates/gba-pulse-template.html

Optionally @ index.html so the model sees the exact CSS classes for `.topic`, `.why-box`, etc.

Two model runs (separate chats or sequential in one chat after changing model)
---------------------------------------------------------------------------------
1) Composer 2 — open Composer, set model to **Composer 2**, then ask:

     Run GBA Pulse. Output a single HTML fragment for my site: inside one
     <main class="wrapper">, include exactly ten .topic blocks (ranks 1–10),
     then Key Observations, Sources, Notes for Tomorrow — matching the
     structure in index.html. Do not include <html> or <head>.

2) Claude Sonnet 4.6 — new Agent chat, model **Claude Sonnet 4.6**, same instruction.

Where to paste in index.html
-----------------------------
Search for these element ids and replace only the inner <main class="wrapper"> … </main> of each panel (keep the outer <div id="panel-…">):

  id="panel-claude"     → Claude Sonnet 4.6 run
  id="panel-composer"   → Composer 2 run

Trending News (overall)
-----------------------
Edit id="panel-overall": replace the ten topics (and sections below) with your **merged** Top 10 using overlap, velocity, and impact across **Claude + Composer only** (see orchestration/COPY_FOR_PARALLEL_AGENTS.txt CHAT D).

Preview locally
---------------
From this project folder:

  python3 -m http.server 8765

Open http://localhost:8765/index.html

Parallel runs (see orchestration/PARALLEL_BRIEFING.txt)
-------------------------------------------------------
Two Cursor sessions (or one SDK script with Promise.all) can each write
orchestration/fragments/claude.html and composer.html, then CHAT D merges to overall.html, then:

  node scripts/merge-briefing-panels.mjs

That updates index.html in one pass (no concurrent writes to the same file).

Commit and push `index.html` (and any assets). Point your static host at the repo root so `index.html` is the default document.
