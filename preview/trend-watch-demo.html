Trend Watch

Four platforms in columns with ranks #1–#5. Google Trends adds a location control (default Hong Kong) and a composite score from volume, growth, and lift vs the top-50 average for that geo.

Must use a local server (opening this file as file:// will not load JSON). From the project root run e.g. python3 -m http.server 8765 → http://localhost:8765/preview/trend-watch-demo.html If port 8765 is busy, try 8766 or another free port and change the URL accordingly.
